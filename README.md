📅 Calendar – HTML, CSS & JavaScript

This is a simple and modern Calendar Web App made using HTML, CSS, and JavaScript.

I built this project to practice JavaScript and create something useful that works directly in the browser. The calendar lets you move between months, go back to today, select a date, and add events.

✨ Features
📅 Shows the current month and year
◀️ Move to the previous month
▶️ Move to the next month
📍 Quickly return to today's date
🖱️ Click on any date
📝 Add events to a specific date
🗑️ Delete events
💾 Events are saved using browser localStorage
📱 Responsive design for mobile and desktop
🎨 Clean and simple user interface
🛠️ Technologies Used
HTML5 – Used to create the calendar structure
CSS3 – Used for styling and responsive design
JavaScript – Used to make the calendar interactive
LocalStorage – Used to save events in the browser

🚀 How to Run the Project

You don't need to install anything.

Download or clone this project.
Open the project folder.
Open index.html in your browser.
The calendar will start working immediately.

You can also use VS Code with the Live Server extension for a better development experience.

📝 How to Add an Event

Adding an event is very simple:

Click on any date.
A popup will appear.
Enter your event name.
Click Add Event.
Your event will appear on the selected date.

Events are saved in your browser, so they will still be there after you refresh the page.

💡 What I Learned

While making this project, I practiced working with JavaScript dates, DOM manipulation, event listeners, arrays, objects, and localStorage.

It was also a good way to understand how HTML, CSS, and JavaScript work together to create an interactive website.


The calendar has a clean monthly layout where you can navigate through months and manage events directly from the browser.
